Phase 1 measures AGREEMENT BETWEEN ARMS. The reference arm is a pseudo-label,
not truth. No claim in this report is a claim about correctness; ground-truth
labels and calibration metrics arrive in Phase 2 from a human-labelled set.

SCOPE OF THE BASELINE. The cc_* arms are Claude Code as it actually ships,
invoked headless on a subscription. They bundle the model with a ~5K-token
preamble, a tool round trip and a process spawn. Every comparison below is
therefore a claim about CLAUDE CODE AS DEPLOYED, not about Opus 5 or Haiku 4.5
as classifiers. A bare Messages API call answers the same question with roughly
386 input tokens in under a second. See the attribution table in each surface
section, and FINDINGS.md Appendix C.
